# Testing Automation Tasks

## Test Suite Generation

```
Generate comprehensive test suite for the payment module,
including unit tests, integration tests, and edge cases.
Target: 90% code coverage
```

## API Contract Tests

```
Create contract tests for the REST API based on OpenAPI spec,
covering all endpoints, error responses, and edge cases
```

## E2E Test Suite

```
Build end-to-end tests for the checkout flow using Playwright,
including happy path, error handling, and payment scenarios
```

## Performance Tests

```
Create load tests for the API using k6, simulating 1000 concurrent
users with realistic usage patterns. Generate performance report.
```

## Regression Test Maintenance

```
Update existing test suite to match new API changes,
fix broken tests, and add tests for new endpoints
```
