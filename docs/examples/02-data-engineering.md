# Data Engineering Workflows

## ETL Pipeline

```
Build an ETL pipeline that extracts sales data from PostgreSQL,
transforms it (aggregations, cleanup), and loads into BigQuery
```

## Data Validation

```
Create a data validation pipeline that checks incoming CSV files
for schema compliance, duplicates, and data quality rules
```

## Stream Processing

```
Build a Kafka consumer that processes user events in real-time,
enriches them with user profiles, and writes to Elasticsearch
```

## Schema Migration

```
Generate migration scripts to evolve the database schema from v1 to v2,
including data transformation for existing records
```

## Data Sync

```
Create a service that syncs data between Salesforce and PostgreSQL
bidirectionally, handling conflicts and rate limits
```
