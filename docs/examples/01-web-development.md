# Web Development Pipelines

## REST API

```
Build a REST API for user management with authentication,
validation, and CRUD operations using Rust and Axum
```

## E-commerce Backend

```
Create an e-commerce backend with product catalog,
shopping cart, and checkout flow. Include Stripe integration.
```

## GraphQL API

```
Build a GraphQL API for a blog platform with posts,
comments, and user profiles. Add real-time subscriptions.
```

## Microservice

```
Create a notification microservice that sends emails,
SMS, and push notifications. Include retry logic and templates.
```

## Frontend Component

```
Build a React dashboard component with charts, filters,
and data tables. Support dark mode and responsive design.
```
